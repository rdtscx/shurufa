Fcitx5 for Android · 输入法

Fcitx5 输入法框架与引擎的 Android 移植版本。本仓库为 fcitx5-android/fcitx5-android 的完整源码镜像，默认分支 main。

包名 org.fcitx.fcitx5.android minSdk 23 · compileSdk 36 4 种 ABI LGPL-2.1-or-later

支持的输入语言

拼音全拼、双拼、五笔、仓颉与自定义码表，由 fcitx5-chinese-addons 驱动
注音通过 Chewing 插件提供
粤拼通过 Jyutping 插件提供，由 libime-jyutping 驱动
越南语通过 UniKey 插件支持 Telex / VNI / VIQR
日语 / 韩语通过 Anthy / Hangul 插件提供
其他僧伽罗语（Sayura）、泰语（Thai）、通用（RIME，可导入自定义方案）

已实现的功能

  • 虚拟键盘（布局暂不可自定义）、长按弹出键盘
  • 候选窗：浮动、水平、展开三种布局
  • 剪贴板管理（纯文本）
  • 主题：自定义配色、背景图，Android 12+ 动态取色
  • 按键弹出预览、符号与表情选择器
  • 插件系统：可从其他已安装的 APK 加载扩展
  • 物理键盘下的浮动候选面板
架构：核心逻辑运行在守护进程（FcitxDaemon，前台服务承载原生 fcitx5），通过 AIDL / IPC 与主进程通信。

仓库结构

app主应用：输入服务、候选窗、软键盘、设置界面、资源与文案
lib核心库：fcitx5、fcitx5-lua、libime、fcitx5-chinese-addons、common（IPC）、plugin-base
plugin插件模块：anthy、chewing、clipboard-filter、hangul、jyutping、rime、sayura、thai、unikey
codegen / build-logicKSP 键位映射生成器、共享 Gradle 约定插件
原生部分（CMake / JNI）的依赖源码以 Git 子模块形式引入，见 .gitmodules；克隆后需执行 git submodule update --init --recursive 后才能构建。

构建

  • 依赖：Android SDK（Platform 与 Build-Tools）、Android NDK 与 CMake、extra-cmake-modules、gettext
  • 推荐版本记录在 build-logic/convention/src/main/kotlin/Versions.kt
  • CI 覆盖：PR 多平台构建、F-Droid 多 ABI 构建、Nix 构建、发布
  • 下载：优先取上游仓库 Release / F-Droid / Jenkins，APK 签名相互兼容
完整文档与下载渠道见仓库 README.md。
